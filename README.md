# Smart Auto — сайт автосервиса

Демо: https://den4ikkonovlov-netizen.github.io/smart-auto-demo/

Готовый статический сайт находится в `dist/`. Сборка и установка пакетов не нужны. Фотографии и шрифты размещены локально; карта 2ГИС загружается отдельно при прокрутке к ней.

## Как запустить на Windows

Откройте командную строку и выполните:

```cmd
cd /d "ПУТЬ_К_ПАПКЕ\SmartAuto"
npm run dev
```

Затем откройте `http://127.0.0.1:4173/`. Оставьте окно командной строки открытым на время просмотра. Чтобы остановить сервер, нажмите `Ctrl+C`.

Если сайт уже был запущен до обновления карты, остановите старый сервер через `Ctrl+C` и запустите команду снова: его прежний заголовок безопасности блокирует виджет 2ГИС.

Команда `npm install` не нужна: в проекте нет внешних пакетов. Если порт 4173 уже занят, можно выбрать другой:

```cmd
set PORT=4174
npm run dev
```

## Публикация на GitHub Pages

При отправке изменений в ветку `main` workflow `.github/workflows/pages.yml` проверяет сайт и публикует содержимое `dist/` на GitHub Pages. Для нового репозитория в настройках **Settings → Pages → Build and deployment** нужно выбрать источник **GitHub Actions**. Файл `dist/.nojekyll` сохраняет статические файлы без обработки Jekyll.

## Возможности

- Адаптивная вёрстка, раскрытие hero диагональной маской, последовательная анимация заголовка, лёгкий параллакс, появление разделов при прокрутке.
- Выбор из шести направлений услуг с обновлением описания и темы записи.
- Запись через телефон и официальное сообщество ВК. Серверной формы отправки заявок нет; сайт не показывает ложного подтверждения записи.
- Галерея, управление стрелками клавиатуры, FAQ, мобильное меню, закреплённые кнопки связи.
- Интерактивная карта 2ГИС в блоке контактов вместо фотографии входа, с адресной карточкой Smart Auto под картой и прямой ссылкой на неё. Для загрузки карты требуется интернет. Если браузер блокирует встроенную карту, в том же блоке остаётся ссылка на карточку в 2ГИС.
- Учёт `prefers-reduced-motion`, видимый фокус, возврат фокуса после диалогов и стандартная клавиша Escape.

## Безопасность

- Нет сторонних JavaScript-библиотек, SDK, счётчиков, пользовательских загрузок, секретов, API-ключей и внешних вызовов из JavaScript.
- Нет `eval`, HTML-инъекций, inline-обработчиков, хранения данных в localStorage или cookies.
- Динамический текст обновляется через `textContent`; пути фотографий выбираются из фиксированного списка.
- CSP ограничивает скрипты, стили, шрифты и изображения текущим источником; запрещает сетевые вызовы JavaScript, объекты и отправку форм. Фрейм разрешён только с `widgets.2gis.com`.
- Внешний виджет карты изолирован в iframe и загружается отложенно. При его использовании действуют правила 2ГИС.
- Файл `_headers` содержит защитные заголовки для совместимого статического хостинга. CSP также задана в HTML, поэтому применяется независимо от поддержки `_headers`.
- Для внешних вкладок заданы `noopener noreferrer`.
- Это проверка данной реализации, а не гарантия отсутствия всех возможных уязвимостей. При добавлении формы, CRM, аналитики или серверной части потребуется отдельная проверка.

## Проверки

`node --check dist/app.js`

`node check.mjs`

Для первоначальной версии проверены в браузере ширины 1280, 390 и 320 px, переключение услуг, запись с выбранной темой, галерея, FAQ и мобильное меню. Последние правки разделов и карты прошли автоматическую проверку и HTTP-проверку локального сервера; визуальную проверку в браузере нужно повторить.
